# 申悦学习 · AI 指导数学学习

从国庆假期（2026.10.1–7）备战高二第一次月考开始，用结构化知识库陪伴申悦到 2028 年高考的数学学习项目。

**运作模式**：每逢长假设计一期"专项复习计划"（诊断→主攻→模拟→复盘），平时用知识库做常态化碎片复习。专项没用完的卡片和真题回流储备池，下期直接调用。

## 网站内容（发布到 GitHub Pages）

- **首页**：项目导览与时间线
- **国庆 7 天辅导计划**：摸底诊断 → 空间向量与立几主线突破 → 直线与方程机动线 → 华附卷模拟与错题复盘（依据广州四校真题分析）
- **长假专项复习设计框架**：小长假/长假专项的通用设计模板，国庆专项为首期实例
- **家长数学速成指南**：空间向量与立体几何篇，写给很久没碰数学的家长
- **数学知识库**：概念卡 4 + 题型卡 2 + 思想方法 2 + 陷阱卡 1 + 过关 30 问 + 四校真题分析报告（常态化学习资源储备）
- **卡片结构**：每张卡 = 核心内容（学）+ 费曼讲解（讲）+ 解题示范（练）+ 复盘要点（复盘），每页可一键打印，适合碎片化复习

## 目录结构

```
国庆7天辅导计划_10月1-7日.md      # 网站内容源：国庆专项计划
家长支持/长假专项复习设计框架.md    # 网站内容源：长假专项通用模板
家长支持/家长数学速成指南_空间向量与立体几何篇.md # 网站内容源：家长指南
家长支持/家长提问卡_费曼回话题库.md  # 网站内容源：口试 30 问
知识库/                          # 网站内容源：全部知识卡片（Markdown，常态化资源储备）
知识库/数学/素材与拓展/真题试卷/    # 2025.10 广州四校月考真题原卷+解析 PDF
build_site.py                   # 构建脚本：Markdown -> docs/ 静态网站
build_print_pack.py             # 构建脚本：知识卡片 -> 打印包/国庆打印包_数学.pdf
docs/                           # 生成的网站（GitHub Pages 发布此目录）
package.json                    # 本地预览：npm run dev
```

## 日常维护（每次更新内容只需三步）

1. 修改对应的 Markdown 文件（或直接让 AI 把错题"入库数学"）
2. 运行 `python build_site.py` 重新生成 `docs/`（改了卡片想更新打印包则再跑 `python build_print_pack.py`）
3. 提交并推送到 GitHub，网站自动更新

家长数学速成指南 · 空间向量与立体几何篇

写给很久没碰数学的家长：您不需要会做题。这篇指南用 30 分钟帮您建立「空间向量」的直觉， 让您能听懂孩子的回讲、问出好问题、看出她卡在哪一步。 月考范围：选必一《空间向量与立体几何》+《直线与方程》（依据：广州四校 2025.10 月考真题分析）。

一、30 秒建立直觉：向量 = 带方向的搬家指令

孩子这学期学的「空间向量」，听起来吓人，其实就是您每天都在用的东西：

  • 向量 = 一条带方向的搬家指令：「往东 3 步、往北 4 步、往上 2 步」，写成 $(3,4,2)$ 就是坐标。
  • 向量相加 = 两条指令连着走。
  • 数量积（两个向量点乘）= 衡量两条路线的「顺路程度」：方向完全一致时最大，垂直时为 0，反方向为负。
  • 法向量 = 垂直戳出平面的一根「旗杆」。有了旗杆，所有「线和面夹多少度」的问题都变成「箭和旗杆夹多少度」。

为什么孩子要学这个：立体几何以前靠「空间想象力」硬想，现在靠向量把几何题变成算数题——想象力不够，计算来凑。这是整个学期最重要的思想。

二、月考考什么（一张图看懂）

四校真题告诉我们，月考立几大题是固定三步曲：

第几步 考什么 孩子要会什么
第（1）问 证明平行/垂直 中位线、判定定理（送分，书写别漏条件）
第（2）问 求角度/距离 建系五步走（见下）
第（3）问 动点/最值/存在性 设参数 $\lambda$ 列方程

建系五步走（孩子必须倒背如流的流程）：

  1. 找三垂直——在图里找一个「房间角落」（三条互相垂直的棱）当坐标轴
  2. 写坐标——给每个点发「门牌号」
  3. 求向量——方向向量直接减，法向量列两个方程解
  4. 套公式——四套公式（异面角、线面角、二面角、距离）
  5. 检验——答案的数值范围对不对

三、您能听懂的三道例题（让孩子讲给您听）

例 1（垂直判断）：「为什么两个向量点乘等于 0 就是垂直？」

期待听到的：数量积衡量顺路程度，垂直时一点顺路成分都没有，所以是 0。反过来算出来是 0 就证明垂直了——不用画图。

例 2（线面角）：「求线面角为什么公式出来是 sin 不是 cos？」

期待听到的：旗杆（法向量）垂直于地面，箭（直线）和旗杆的夹角越接近 90°，箭越平。箭与地面的角 = 90° − 箭与旗杆的角，所以是 sin。

例 3（直线的截距陷阱）：「过点 $(2,1)$ 截距相等的直线有几条？」

期待听到的：两条！一条斜着切（$x+y=3$），一条过原点（$y=x/2$）——过原点时两个截距都是 0，也算「相等」，最容易漏。

四、批改四问清单（看孩子作业/试卷时用）

不用看懂过程，只看四个地方：

  1. 建系了吗？ 立几大题第（2）问起，卷面上应该出现坐标系和一堆点坐标。没有坐标 = 她在硬想，提醒用建系法。
  2. 坐标验了吗？ 问她「你检查过坐标没」——抄错坐标是最大失分源。
  3. 公式套对了吗？ 只记一句：线面角公式出来的是 sin。看到她把 cos 直接当线面角答案，就是踩坑了。
  4. 范围验了吗？ 动点题解出的 $\lambda$ 要在 $[0,1]$ 里；sin/cos 的值不能超过 1。

五、常见问题答疑

Q：孩子说我问的太简单，不想讲怎么办？ A：换个角色——您不是考她，是「采访」她：「这个法向量是干嘛的？给我打个比方呗。」被采访的专家最有表达欲。

Q：她讲错了我能纠正吗？ A：不要纠正。说「这个我有点没听懂，你再讲讲？」让她自己发现矛盾。您一纠正，「小老师」就变回「被检查的学生」了。

Q：立体几何我当年就差，怎么陪她？ A：正好！您就大方说「妈妈/爸爸当年空间想象也差，你给我讲讲这个向量法怎么不用想象就能做题」——让她教您一个「差生也能懂」的方法，她的成就感最强。

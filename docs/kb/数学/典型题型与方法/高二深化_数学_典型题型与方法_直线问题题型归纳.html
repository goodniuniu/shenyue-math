核心内容

题型 1：直线与线段相交求参数范围（华附题 5 原型） 直线 $l$ 过定点 $P$，与以 $A,B$ 为端点的线段相交 → $k_l$ 介于 $k_{PA}$ 与 $k_{PB}$ 之间，但当 $PA,PB$ 分居竖直线两侧时，范围要取「两边」（$k\geq k_1$ 或 $k\leq k_2$）。先画图判断竖直线是否穿过扇形。

题型 2：点关于直线对称（华附题 6 原型） 两方程联立：①中点在对称轴上；②两点连线与对称轴垂直。对称轴为 $y=x$ 或 $y=-x$ 时可直接换坐标速算。

题型 3：直线上动点距离和最值（铁一题 16 原型：$\lvert PA\rvert+\lvert PB\rvert$ 最小 / $\lvert\lvert PA\rvert-\lvert PB\rvert\rvert$ 最大）

问题 方法 结论
$A,B$ 在直线异侧，求 $\lvert PA\rvert+\lvert PB\rvert$ 最小 直接连 $AB$，交点即 $P$ 最小值 $=\lvert AB\rvert$
$A,B$ 在直线同侧，求 $\lvert PA\rvert+\lvert PB\rvert$ 最小 作 $A$ 关于直线的对称点 $A'$，连 $A'B$ 最小值 $=\lvert A'B\rvert$（将军饮马）
求 $\lvert\lvert PA\rvert-\lvert PB\rvert\rvert$ 最大 同侧直连、异侧先对称，延长交直线 最大值 $=\lvert AB\rvert$ 或 $\lvert A'B\rvert$（三角形两边之差小于第三边取等）

题型 4：过定点直线与坐标轴围成面积最值（华附 17(2)、广附 15(2) 原型） 设截距式 $\dfrac{x}{a}+\dfrac{y}{b}=1$（$a,b>0$），点在直线上得约束 $\dfrac{x_0}{a}+\dfrac{y_0}{b}=1$，用基本不等式：$1\geq 2\sqrt{\dfrac{x_0y_0}{ab}}$ → $ab\geq 4x_0y_0$ → $S=\dfrac12 ab\geq 2x_0y_0$，取等条件 $\dfrac{x_0}{a}=\dfrac{y_0}{b}=\dfrac12$。

题型 5：含参直线讨论（平行/垂直求参数） 垂直用万能式 $A_1A_2+B_1B_2=0$；平行用系数成比例后必须回代排除重合（多解陷阱）。

🗣️ 费曼讲解（讲给零基础的人听）

「将军饮马」是最有名的几何最值故事：将军从军营出发，要到河边让马喝水，再回营地，怎么走最近？答案是把河当镜子，把营地「照」到河对岸，直线一连就是最短路线——因为镜子里外距离相等，折线被拉直了。数学里所有「直线上找一点使距离和最小」都是这个故事。距离差最大则反过来：三角形两边之差永远小于第三边，把三点拉到一条线上时取到最大。

📝 解题示范（一道典型题完整流程）

题（铁一卷题 16(1) 原型）：$A(2,1)$，$B(1,2)$，在直线 $l:y=x$ 上求一点 $P$ 使 $\lvert PA\rvert+\lvert PB\rvert$ 最小。

  1. 判同侧异侧：代入 $y-x$：$A$ 得 $-1<0$，$B$ 得 $1>0$ → 异侧
  2. 异侧直接连 $AB$：与 $y=x$ 的交点即 $P$
  3. 直线 $AB$：斜率 $\dfrac{2-1}{1-2}=-1$，方程 $y-1=-(x-2)$ 即 $x+y=3$
  4. 联立 $y=x$ 得 $P\left(\dfrac32,\dfrac32\right)$，最小值 $\lvert AB\rvert=\sqrt2$
  5. 检验：若判成同侧用了对称点，会得多余计算；异侧直连才对。$P$ 在线段 $AB$ 上，和确实等于 $\lvert AB\rvert$ ✓

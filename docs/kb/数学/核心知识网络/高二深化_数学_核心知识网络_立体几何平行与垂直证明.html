【立体几何平行与垂直证明】解答题第（1）问的送分套路

核心内容

四校真题规律：每卷立几大题第（1）问都是证明题（证线面平行或线线/线面垂直），用综合几何法更快；第（2）（3）问求角求距离才建系。

判定定理一句话版：

要证 用哪条 口诀
线面平行 在平面内找一条线与它平行 「面内找平行」
线面垂直 该线垂直于面内两条相交直线 「垂直两条相交线」
面面垂直 一个面内有一条线垂直另一个面 「面内垂线垂对面」
线线垂直 先证线面垂直，线垂直面内一切线 「线垂面 → 线垂线」

两大高频辅助手段：

  1. 中点 → 中位线：题干给中点，优先想中位线造平行（真题里 $E,F$ 是中点几乎必用）。
  2. 面面垂直 → 线面垂直：已知「平面 $\alpha\perp$ 平面 $\beta$」，立刻在其中一个面内找垂直于交线的直线，它垂直另一个面（这是翻折题的标准第一步）。

翻折题三不变：翻折前后，同一半平面内的长度、角度、垂直关系不变——先把折叠前平面图里的关系标清楚，再搬到立体图。

🗣️ 费曼讲解（讲给零基础的人听）

证明题像过海关：想让一条直线「进入」平面（平行），你得在面内给它找一个「老乡」（平行线）接应；想证明它「管得住」整个平面（垂直），光镇住一条线不行，得镇住两条相交的线——就像按住跷跷板的两头，整个板才动不了。中点就是出题人送的梯子：两个中点一连，中位线自动平行且减半，梯子递到你手里了一定要爬。

📝 解题示范（一道典型题完整流程）

题（执信卷题 16 原型）：四棱锥 $P$-$ABCD$ 底面是菱形，平面 $PAC\perp$ 平面 $ABCD$，$E,F$ 分别是 $PA,PB$ 中点。证明：$EF\parallel$ 平面 $ABCD$。

  1. $E,F$ 是 $PA,PB$ 中点 → 在 $\triangle PAB$ 中 $EF$ 是中位线
  2. 故 $EF\parallel AB$
  3. $AB\subset$ 平面 $ABCD$，$EF\not\subset$ 平面 $ABCD$
  4. 由线面平行判定定理，$EF\parallel$ 平面 $ABCD$
  5. 检验：三要素齐全——「面内一条线（AB）」「与它平行（EF∥AB）」「EF 不在面内」，缺一不可。

通法：写证明时默念三件套——找线、证平行（或垂直）、交代在不在面内。改卷按点给分，漏「EF 不在平面内」要扣 1 分。

✅ 复盘要点（自测清单，能讲清即打勾）

  • [ ] 能默写线面平行、线面垂直、面面垂直的判定定理
  • [ ] 见到「平面 α⊥平面 β」能立刻反应出「找垂直于交线的线」
  • [ ] 见到中点能立刻想到中位线
  • [ ] 能讲清翻折前后「什么不变」
  • [ ] 证明书写不漏「线不在面内」等关键交代

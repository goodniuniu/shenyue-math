## 核心内容

**一句话**：题目要求的量设为未知数，把题目条件一条条翻译成方程（组），解出来就是答案——条件有几个独立等式，就能求几个未知数。

**当前学期的高频战场**：

| 场景 | 设谁 | 方程从哪来 |
|------|------|-----------|
| 求直线方程 | 斜率 $k$ 与截距 $b$（或两点式坐标） | 一个条件列一个方程：过点 → 代入；垂直 → 斜率乘积 $-1$；距离 → 距离公式 |
| 动点轨迹/定点问题 | 动点坐标 $(x,y)$ | 把「距离相等」「垂直」「中点」等条件翻译成 $x,y$ 的等式 |
| 含参直线恒过定点 | 定点 $(x_0,y_0)$ | 按参数 $m$ 整理成 $A+mB=0$，令 $A=0$ 且 $B=0$ 联立 |
| 向量建系后求点坐标 | 该点坐标分量 | 长度条件、垂直条件、共面条件各出一个方程 |
| 最值问题 | 目标量写成某变量的函数 $f(x)$ | 定义域来自几何约束，再用单调性/基本不等式求最值 |

**使用仪式**：读题时每看到一个条件就问自己「它能写成关于未知数的哪个等式」。条件用完方程不够，多半是漏了隐含条件（相切、共线、点在图形内部）。

## 🗣️ 费曼讲解（讲给零基础的人听）

这就像**破案拼图**：要求的答案是「失踪的人」，每条题目条件都是一条线索，一条线索能锁定一个特征。两条线索锁定两个特征，人就找出来了。孩子做题卡住时，常犯的错误是线索（条件）还没用完就急着算。提醒一句：**把条件逐条画勾，每条都变成了方程没有？** 最怕的是「想当然」——比如题目说「相切」却只凭感觉画图，不把「距离等于半径」写成等式。

## 📝 解题示范（一道典型题完整流程）

> 题（直线含参原型）：直线 $(2x+y-1)+m(x-y+2)=0$ 无论 $m$ 取何值恒过定点，求该定点。

1. **设**：定点 $P(x_0,y_0)$——「无论 $m$ 取何值都成立」说明 $x_0,y_0$ 与 $m$ 无关
2. **列方程**：按 $m$ 整理，原式 $=(2x+y-1)+m(x-y+2)$，要让它对任意 $m$ 都等于 0，必须两部分同时为 0：
   $2x_0+y_0-1=0$ 且 $x_0-y_0+2=0$
3. **解**：两式相加得 $3x_0+1=0$，$x_0=-\dfrac{1}{3}$，代回得 $y_0=\dfrac{5}{3}$
4. **检验**：把 $\left(-\dfrac{1}{3},\dfrac{5}{3}\right)$ 代回原直线，两个括号都等于 0，确实与 $m$ 无关 ✓

## ✅ 复盘要点（自测清单，能讲清即打勾）

- [ ] 能说清「一个独立条件 ↔ 一个方程 ↔ 一个未知数」的对应关系
- [ ] 见到「恒过定点」「任意 $m$ 都成立」会反应「按参数整理、系数分别为 0」
- [ ] 求直线方程时会先数「我有几个条件、需要几个未知数」，再选方程形式
- [ ] 条件用完方程还不够时，会回头找隐含条件（相切、共线、中点）

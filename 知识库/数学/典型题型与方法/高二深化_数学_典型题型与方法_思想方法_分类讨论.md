## 核心内容

**一句话**：当题目因参数、位置或形状不同而有多种可能时，按「不重不漏」的原则把情况分开，每种情况单独求解，最后合并作答。

**当前学期的讨论触发器（见到就警觉）**：

| 触发信号 | 为什么要讨论 | 常见分法 |
|----------|--------------|----------|
| 直线斜率「是否存在」 | 竖直线没有斜率，公式直接失效 | 竖直 / 非竖直两类 |
| 含参数 $a$ 的系数 | $a=0$ 时常让整个式子变性（二次退化为一次） | 系数为零 / 不为零 |
| 点与直线、点与圆的位置关系 | 位置不同，距离公式用法与最值结论不同 | 同侧 / 异侧；圆内 / 圆上 / 圆外 |
| 截距式、对称点问题 | 「截距相等」包含过原点这种隐藏特例 | 过原点 / 不过原点 |
| 向量夹角与投影 | 夹角是锐角还是钝角决定符号 | 锐角 / 直角 / 钝角 |
| 翻折、动点问题 | 动点在不同边上、翻折方向不同，图形本质不同 | 按动点所在边/区间分段 |

**使用仪式（四步）**：①找分界：什么值会让情况发生质变；②排顺序：按参数轴从左到右列情况；③逐段求解：每段用该段的公式；④合并检验：各段答案是否都满足本段前提，分界点单独验证。

## 🗣️ 费曼讲解（讲给零基础的人听）

这就像**分情况点菜**：「今天吃什么」取决于下没下雨——下雨点外卖，不下雨去食堂。如果只想一种方案，天气一变就饿肚子。数学里的参数就像天气，题目不告诉你它取什么值，你就得把几种「天气」分别安排明白，最后说一句「如果这样就……，如果那样就……」。孩子最常丢分的地方不是不会算，而是**漏了一种情况**——比如用斜率公式时忘了竖直线没有斜率，或者忘了「截距相等」还包括两条截距都是 0 的直线。提醒一句：**列公式之前先问，这个公式有没有用不了的情形？**

## 📝 解题示范（一道典型题完整流程）

> 题（截距陷阱原型）：求过点 $P(2,1)$ 且在两坐标轴上截距相等的直线方程。

1. **找分界**：截距式 $\dfrac{x}{a}+\dfrac{y}{a}=1$ 只在 $a\neq0$ 时能用 → 分「截距为 0」与「截距不为 0」
2. **情况一（不过原点，$a\neq0$）**：设 $\dfrac{x}{a}+\dfrac{y}{a}=1$，代入 $P(2,1)$：$\dfrac{3}{a}=1$，$a=3$，直线为 $x+y-3=0$
3. **情况二（过原点）**：截距都为 0，直线过 $(0,0)$ 与 $(2,1)$，斜率 $\dfrac{1}{2}$，即 $x-2y=0$
4. **合并检验**：两条都过 $P(2,1)$ 且截距相等 ✓。答：$x+y-3=0$ 或 $x-2y=0$（漏掉第二条是本题经典错因）

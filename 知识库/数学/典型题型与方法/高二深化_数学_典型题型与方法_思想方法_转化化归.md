## 核心内容

**一句话**：正面难走就绕道——把陌生问题转化为熟悉问题，把复杂问题拆解为简单问题。

**本学期高频转化方向对照表**：

| 转化方向 | 怎么转 | 真题例子 |
|----------|--------|----------|
| 空间问题 → 平面问题 | 截面、展开图、投影 | 圆台/圆锥侧面展开求最短路径 |
| 几何关系 → 代数方程 | 建系：垂直=数量积为 0，角度=夹角公式 | 全部立几解答题第（2）（3）问 |
| 异面直线角 → 相交直线角 | 平移其中一条（中位线常是天然平移） | 华附题 5、执信题 5 |
| 二面角 → 两法向量夹角 | 求两个平面的法向量 | 华附 18(3)、广附 17(2) |
| 翻折问题 → 平面图形 + 不变量 | 翻折前后同一半平面内长度角度不变 | 华附 18、广附 19 |
| 动点最值 → 一元函数最值 | 设 $\lambda$ 参数化动点，目标量写成 $\lambda$ 的函数 | 各卷 11 题、18/19(3) |
| 新定义题 → 已知知识 | 逐句把新定义「翻译」成学过的概念 | 铁一 19「完美三棱锥」= 对棱数量积关系、执信 19 新定义函数 |
| 存在性问题 → 方程有解问题 | 设存在，列方程，讨论解是否在范围 | 广附 19(3)、执信 18(3) |

**使用仪式**：读题卡住时问三个问题——「这题让我求的东西，本质上是什么？」「我学过的哪个工具能碰它？」「能不能先退到简单情形（取特殊值/特殊位置）探路？」

## 🗣️ 费曼讲解（讲给零基础的人听）

转化化归就像**汇率兑换**：手里有一种外币（陌生的题），花不出去；换成人民币（学过的知识）就能用了。数学家最喜欢干的事就是「兑换」——立体几何不会算？换成代数（建系）。空间图形想不清？压扁成平面图（截面展开）。题目给了个没听说过的新名词？别慌，把定义逐句翻译，十有八九就是老朋友化了妆。考场上真正的差距，不是谁背得多，是**谁会换**。

## 📝 解题示范（一道典型题完整流程）

> 题（铁一卷题 19 原型）：定义「完美三棱锥」：三棱锥 $P$-$ABC$ 满足 $\vec{PA}\cdot\vec{BC}=\vec{PB}\cdot\vec{AC}=\vec{PC}\cdot\vec{AB}$（对棱方向的数量积关系）。判断给定三棱锥是否为完美三棱锥。

1. **翻译新定义**：三个等式本质 = 三组对棱位置关系的代数条件
2. **转化为计算**：写出各点坐标（或设向量），逐个计算 $\vec{PA}\cdot\vec{BC}$ 等三个数量积
3. **比对**：三个值相等 → 是；否则不是
4. **拓展**：由 $\vec{PA}\cdot\vec{BC}=0$ 的特殊情形可发现「对棱垂直」是完美三棱锥的常见实现（正三棱锥即满足）
5. **检验**：新定义题不需要「见过」，只需要「翻译得对」——把定义式原样代回验算一遍。
